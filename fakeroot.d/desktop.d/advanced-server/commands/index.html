Advanced Server — Commands

Command Prefixes

Both . and : prefixes work identically for all in-game chat commands.

Lobby Commands

CommandOp levelDescription
.help [1-5]Command reference (5 pages).
.infoServer information: version and build date.
:creditsProject authors.
:sourceLink to the source code repository.
.stink <player>Public taunt directed at another player.
.lobby <N>Switch to a different lobby by number.
.yes / .yVote "yes" in the current vote.
.vk <player>Start a votekick against a player. Requires 3+ players; has a cooldown.
.vpStart a vote for a practice round (map selection).
:vm <N>Vote for a specific map by its number.
:status [1-4]Server statistics (kills, shots, clones, etc.). 4 pages.
.map <map>≥ 1Force a specific map for the next game.
:chance <0-100>≥ 1Set your personal chance of becoming EXE.
.kick≥ 2Open the player kick UI.
.ban≥ 2Open the player ban UI.
:stop≥ 2Force the current round to end immediately.
:start≥ 2Force the game to start (proceeds to map selection).
.op≥ 3Open the UI to grant operator rights to a player.
:reboot≥ 3Reset the lobby to its initial state.
.vk, .vp, and :vm are disabled when authoritarian_mode or anonymous_mode is active.
During map voting, only .vp, .yes, and .y are accepted — and only from operators, to forcefully conclude the vote.

Server CLI Commands

Entered directly in the server terminal. Prefix: ?

CommandDescription
?helpList all terminal commands.
?lobby <N>Switch the active lobby.
?playerlistList players in the active lobby.
?playerlist --banned / -bList all bans (IPs, UDIDs, nicknames).
?playerlist --timeouts / -tList active kick timeouts.
?playerlist --admins / -aList all operators.
?kick --pid / --endpoint / --username / --udid [--note]Kick a player.
?ban --pid / --endpoint / --username / --udid [--note]Ban a player.
?pardon --pid / --endpoint / --username / --udidRemove all bans and timeouts from a player.
?op --pid / --endpoint / --username / --udid [--op-level 0-255] [--note]Set a player's operator level.
?say <text>Send a message to the active lobby.
?broadcast <text>Send a message to all lobbies.
?start [--map / -m <map id>]Force the game to start in the active lobby.
?stopForce the current round to end in the active lobby.
?licensePrint the license text.
?haltShut down the server.
