Ice Star — How to Join

Joining Steps

  1. Open the original TD2DR game client.
  2. On the server screen, find the "Enter IP" field.
  3. Type the server address: [domain_expired]
  4. Click Join — you're in!

Important Notes

  • Radmin VPN and ZeroTier-One are not required.
  • The server automatically reboots daily at 3:00 AM UTC (6:00 AM MSK).
